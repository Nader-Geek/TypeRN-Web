UpdateOctober 11, 2025

TypeR 2.3

Style subfolders, tags to ignore and many fixes, including centering and text direction.

On this page

  • New features
  • Fixes
  • 2.3.2

New features

  • Style subfolders. You can now create folders inside other folders for better organization.
  • Tags to ignore. In Settings > General, any prefix you add to "Tags to ignore" won't be inserted when pasting a bubble. With the tag **, the text **Hello World is pasted as Hello World.

Fixes

  • The centering has been fixed to be like 2.1.0 (more precise on complex bubbles).
  • Fixed a bug that inverted punctuation when inserting text.
  • Text direction (left-to-right or right-to-left) now works properly.
  • Fixed a bug that converted Point Text to Paragraph Text when centering.
  • Fixed a bug that cut off text when inserting text into an existing Point Text.
  • The lowercase word "page" is now detected by TypeR.

2.3.2

  • Fixed a bug where applying a style and inserting text changed the text alignment.
  • Fixed centering again.
